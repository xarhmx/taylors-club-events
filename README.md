# Taylor's Club Events

Event management web app for Taylor's University clubs and societies.
ITS64504 Web Application Programming – Group Assignment

## Tech stack
HTML, CSS, JavaScript, PHP, MySQL (MAMP + phpMyAdmin)

## Setup
1. Clone this repo into MAMP's `htdocs` folder
2. Start MAMP and open phpMyAdmin
3. Import `database/taylors_club_events.sql`
4. Check the credentials and port in `includes/db.php`
5. Visit http://localhost:8888/taylors-club-events/ (or port 80 on Windows)
